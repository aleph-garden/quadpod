The terms quadpod mints under `https://w3id.org/quadpod/ns#`. A term enters this namespace
only when no registered vocabulary can carry the claim; everything the pod can say in LDP, WAC,
SHACL, PROV-O or schema.org it says there. This page is read from
[`ns/quadpod.ttl`](../ns/quadpod.ttl) at build time, so it lists exactly what that file defines.
